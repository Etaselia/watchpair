Upgrading an existing v2 copy

Your existing v2 rooms, invites, profile and downloaded media stay in place.

  1. Download alpha.4 and extract every file into a new folder.
  2. Quit older WatchPair copies completely, including the tray icon, then open the newly extracted app. Use your usual profile.
  3. Open Settings → Application and updates and check that Running says 2.0.0-alpha.4.
  4. Choose Install running copy (2.0.0-alpha.4) (or Install this copy for a first installation), wait until it is ready, then restart. Confirm the running version again.

This one-time manual step repairs older copies that restarted into an earlier installed version. Later updates can use the signed feed below. Do not delete your profile or create replacement rooms to upgrade.
